# Test 29N: ¿qué medidas te afectan?

Herramienta neutral y abierta. Hace preguntas sobre la situación de la persona y le devuelve, partido por partido, tres capas: efecto directo, riesgos indirectos y financiación declarada. **No recomienda voto.**

- `data/medidas.json`: preguntas, condiciones, medidas, riesgos, partidos y fuentes. Es la única fuente de verdad.
- `motor.js`: motor de evaluación sin dependencias (Node o navegador).
- `docs/esquema.md`: especificación del JSON y de las condiciones (para aplicarlas a mano).
- `docs/metodologia.md`: criterios, controles de sesgo y limitaciones.

## Procedimiento

1. **Antes de empezar**, di en una o dos frases:
   - que no es una recomendación de voto;
   - la fecha de corte de los datos (`meta.fecha_corte`);
   - qué partidos no tienen programa publicado (`partidos[].programa.estado == "sin_programa"`).

   Si la fecha actual es posterior a `meta.fecha_corte` y puedes buscar en la web, avisa de que los programas pueden haber cambiado. No añadas medidas nuevas al resultado salvo que las verifiques con fuente y las marques como «añadida por el asistente, no forma parte del test».

2. **Haz las preguntas** de `preguntas` en orden. Muestra solo las que cumplan `mostrar_si` con las respuestas dadas hasta ese momento.
   - **Haz todas las preguntas visibles, sin saltarte ninguna.** Vuelve a calcular cuáles son visibles después de cada respuesta.
   - Por defecto, haz una pregunta por mensaje y numera las opciones para que se pueda responder con un número. Si tu interfaz tiene botones o selectores de opciones, úsalos. Si la persona lo pide, agrupa 3 o 4 preguntas por mensaje.
   - Ofrece las opciones literales. Si la persona responde con sus palabras, conviértelo en el `valor` de la opción correspondiente y confírmalo si hay duda.
   - Las preguntas `tipo: "multi"` admiten varios valores (lista). El valor indicado en `ninguno` excluye a los demás.
   - Si alguien prefiere no responder, deja la respuesta sin definir. Las condiciones que dependen de ella cuentan como falsas.
   - No deduzcas respuestas que la persona no ha dado, en especial la nacionalidad o el patrimonio.

3. **Confirma las respuestas.** Antes de evaluar, enseña una tabla con cada pregunta y el valor que vas a usar, y pide confirmación. Indica las preguntas que la persona prefirió no responder.

4. **Evalúa.**
   - Si puedes ejecutar código, usa el motor:
     ```bash
     node -e 'const T=require("./motor.js"),D=require("./data/medidas.json");console.log(JSON.stringify(T.evaluate(D, RESPUESTAS),null,1))'
     ```
     sustituyendo `RESPUESTAS` por el objeto de respuestas (p. ej. `{"region":"resto","edad":"26-35",...}`).
   - Si no puedes, aplica las reglas a mano según `docs/esquema.md`:
     - para cada medida no universal, el primer elemento de `efectos` cuya condición se cumpla da su `valor` (+1, −1 o 0) y su texto; si ninguno se cumple, la medida no te afecta;
     - para cada partido, reúne los `riesgos` de **todas** sus medidas, te afecten o no, y elige la primera `exposicion` que se cumpla;
     - si todos los vínculos de un riesgo en ese partido tienen `escala: "acotada"`, una exposición `alta` baja a `media`;
     - añade las `notas` cuya condición se cumpla.

5. **Presenta el resultado** en este orden y con el mismo formato para todos los partidos (orden alfabético):
   1. **Notas** que apliquen.
   2. **Riesgos indirectos comparados**: una tabla con los riesgos en las filas y los partidos en las columnas, y en cada celda el nivel de exposición (alta, media o baja) o «—» si el partido no lo activa. Indica el nivel de evidencia de cada riesgo.
   3. Para cada partido:
      - **Financiación**: `financiacion.cuantifica` y `resumen`.
      - **Riesgos indirectos para la persona**, ordenados por exposición, con el texto personal y la evidencia.
      - **Efecto directo**: a favor, en contra e incierto. Cada medida separa el **hecho** (texto, origen, número de medida) de la **inferencia** (cómo le afecta).

   Después, ofrece los enlaces de fuentes de lo que la persona quiera comprobar.

   Si añades una síntesis propia, que sea simétrica: en cada tema, nombra las medidas de todos los partidos que tengan algo relevante o no nombres ninguna. Las exposiciones son las del motor; no las subas ni las bajes.

## Reglas de neutralidad (obligatorias)

- No calcules una puntuación total, no ordenes partidos por «beneficio» y no digas qué partido le conviene más. No uses las palabras «clasificación», «ranking» ni «puntuación» para los recuentos. El número de medidas no mide su peso, y los riesgos indirectos no se pueden sumar a los efectos directos.
- Si preguntan «¿a quién voto?», no elijas por la persona. Ayúdale a ordenar sus prioridades y a ver cómo encaja cada partido con ellas, citando los datos del test.
- Mismo tono, extensión y nivel de detalle para todos los partidos. No añadas valoraciones propias sobre partidos o candidatos.
- Mantén las etiquetas de evidencia. No conviertas una evidencia «disputada» en certeza en ningún sentido.
- No guardes las respuestas fuera de la conversación.

## Especificación de los datos

# Esquema de `data/medidas.json`

Un solo archivo JSON con estas claves de primer nivel:

| Clave | Contenido |
|---|---|
| `meta` | Título, versión, `fecha_corte`, aviso y glosarios (`valores`, `evidencia`, `origen`). |
| `condiciones` | Condiciones con nombre, reutilizables con `{"ref": "nombre"}`. |
| `preguntas` | Cuestionario, en orden. |
| `partidos` | Partido, estado del programa y financiación declarada. |
| `riesgos` | Efectos indirectos reutilizables, con nivel de evidencia y exposición según el perfil. |
| `medidas` | Medidas por partido, con sus efectos directos y los riesgos que activan. |
| `fuentes` | Diccionario `id → {titulo, url, fecha}`. |

## Preguntas

```json
{"id":"viv","texto":"¿Cómo es tu vivienda habitual?","tipo":"unica",
 "opciones":[{"valor":"alquiler","texto":"Vivo de alquiler"}],
 "mostrar_si":{"ref":"..."}, "ayuda":"...", "ninguno":"ninguno"}
```

- `tipo`: `unica` (un valor) o `multi` (lista de valores).
- `mostrar_si` (opcional): la pregunta solo se hace si la condición se cumple con las respuestas previas.
- `ninguno` (solo en `multi`): un valor que excluye a los demás.

Las respuestas forman un objeto `{id_pregunta: valor}`. Las respuestas a preguntas ocultas se descartan.

## Condiciones

Una condición es un objeto con una de estas formas:

| Forma | Se cumple si… |
|---|---|
| `{"siempre": true}` | siempre |
| `{"ref": "nombre"}` | se cumple la condición con nombre `condiciones.nombre` |
| `{"all": [c1, c2]}` | se cumplen todas |
| `{"any": [c1, c2]}` | se cumple alguna |
| `{"not": c}` | no se cumple `c` |
| `{"q": "id", "eq": v}` | la respuesta es igual a `v` |
| `{"q": "id", "in": [v1, v2]}` | la respuesta está en la lista |
| `{"q": "id", "gte": n}` / `"lte"` | la respuesta numérica es ≥ / ≤ `n` |
| `{"q": "id", "includes": v}` | la respuesta (lista) contiene `v` |
| `{"q": "id", "includesAny": [..]}` | la respuesta (lista) contiene alguno |

**Regla clave:** si la pregunta `q` no tiene respuesta (no se hizo o la persona no contestó), cualquier comparación sobre ella es **falsa**.

## Medidas

```json
{"id":"pp-179","partido":"pp","tema":"IRPF","texto":"…","num":"179",
 "origen":"programa|campaña|previa","fuentes":["rankia"],
 "efectos":[{"si":COND,"valor":1,"texto":"…"}, …],
 "riesgos":[{"id":"rebaja_sin_financiar","escala":"amplia|acotada"}], "universal":false}
```

- **Efecto directo:** se recorre `efectos` en orden y gana el primero cuya condición se cumple. `valor` vale `1` (a favor), `-1` (en contra) o `0` (incierto o no aplica directamente). Si ninguno se cumple, la medida no afecta a la persona y no se muestra.
- `universal: true`: la medida afecta a casi todos por igual. No tiene efectos personales, pero sí aporta riesgos.
- `riesgos`: riesgos indirectos que la medida activa **para el partido**, afecte o no a la persona. La `escala` vale `amplia` (impuesto o programa general, o coste grande publicado) o `acotada` (colectivo concreto o medida condicional).

## Riesgos

```json
{"id":"rebaja_sin_financiar","titulo":"…","evidencia":"hecho|hecho+inferencia|consenso|disputada|inferencia",
 "que_pasa":"…","fuentes":[…],
 "exposicion":[{"si":COND,"nivel":"alta|media|baja","texto":"…"}, …]}
```

Para cada partido se reúnen los riesgos de **todas** sus medidas, se eliminan duplicados y, para cada uno, gana la primera `exposicion` cuya condición se cumple. La última entrada siempre es `{"siempre":true}`, así que todo riesgo tiene un nivel.

**Regla de escala:** si todos los vínculos de un riesgo en un partido son `acotada`, una exposición `alta` baja a `media`.

**Matriz de riesgos:** el motor devuelve también `matriz_riesgos`, con una fila por riesgo y una columna por partido; cada celda es el nivel de exposición, o `null` si el partido no activa ese riesgo.

## Notas

```json
"notas":[{"si":COND,"texto":"…"}]
```

Avisos contextuales (desempleo, IVA en Canarias, dependencia…) que se muestran cuando se cumple su condición. Así, la web y los asistentes de IA muestran exactamente los mismos avisos.

## Partidos

```json
{"id":"pp","nombre":"PP","ambito_si":COND?,
 "programa":{"titulo":"…","fecha":"AAAA-MM-DD|null","estado":"publicado|sin_programa","nota":"…"},
 "financiacion":{"cuantifica":"no|si|cifras_propias|fuera_del_programa","resumen":"…","fuentes":[…]}}
```

`ambito_si` limita un partido territorial a quien cumpla la condición (p. ej., Coalición Canaria solo para residentes en Canarias). Los partidos se muestran en orden alfabético.

## Motor (motor.js)

```javascript
/*
 * Motor del Test 29N. Sin dependencias. Funciona en navegador (window.Test29N) y en Node (require).
 * Aplica las reglas declarativas de data/medidas.json a un objeto de respuestas.
 * Especificación de las condiciones: docs/esquema.md
 */
(function (root, factory) {
  if (typeof module === 'object' && module.exports) module.exports = factory();
  else root.Test29N = factory();
})(typeof self !== 'undefined' ? self : this, function () {
  'use strict';

  function has(a, k) { return Object.prototype.hasOwnProperty.call(a, k) && a[k] !== undefined && a[k] !== null; }

  function evalCond(c, ans, named) {
    if (!c) return true;
    if (c.siempre) return true;
    if (c.ref) {
      if (!named[c.ref]) throw new Error('Condición desconocida: ' + c.ref);
      return evalCond(named[c.ref], ans, named);
    }
    if (c.all) return c.all.every(function (x) { return evalCond(x, ans, named); });
    if (c.any) return c.any.some(function (x) { return evalCond(x, ans, named); });
    if (c.not) return !evalCond(c.not, ans, named);
    if (c.q) {
      if (!has(ans, c.q)) return false;           // pregunta no respondida u oculta
      var v = ans[c.q];
      if ('eq' in c) return v === c.eq;
      if ('in' in c) return c['in'].indexOf(v) !== -1;
      if ('gte' in c) return v >= c.gte;
      if ('lte' in c) return v <= c.lte;
      if ('includes' in c) return Array.isArray(v) && v.indexOf(c.includes) !== -1;
      if ('includesAny' in c) return Array.isArray(v) && c.includesAny.some(function (x) { return v.indexOf(x) !== -1; });
      throw new Error('Operador desconocido en ' + JSON.stringify(c));
    }
    throw new Error('Condición mal formada: ' + JSON.stringify(c));
  }

  function visibleQuestions(data, ans) {
    return data.preguntas.filter(function (q) { return !q.mostrar_si || evalCond(q.mostrar_si, ans, data.condiciones); });
  }

  // Elimina respuestas de preguntas que han quedado ocultas (p. ej., tras cambiar una respuesta anterior).
  function cleanAnswers(data, ans) {
    var out = {}, vis = visibleQuestions(data, ans);
    vis.forEach(function (q) { if (has(ans, q.id)) out[q.id] = ans[q.id]; });
    // segunda pasada por si una respuesta eliminada ocultaba otra
    var vis2 = visibleQuestions(data, out), res = {};
    vis2.forEach(function (q) { if (has(out, q.id)) res[q.id] = out[q.id]; });
    return res;
  }

  function firstMatch(list, ans, named) {
    for (var i = 0; i < list.length; i++) if (evalCond(list[i].si, ans, named)) return list[i];
    return null;
  }

  var NIVEL = { alta: 3, media: 2, baja: 1 };

  function evaluate(data, rawAns) {
    var ans = cleanAnswers(data, rawAns), named = data.condiciones;
    var riskById = {};
    data.riesgos.forEach(function (r) { riskById[r.id] = r; });

    var partidos = data.partidos
      .filter(function (p) { return !p.ambito_si || evalCond(p.ambito_si, ans, named); })
      .slice().sort(function (a, b) { return a.nombre.localeCompare(b.nombre, 'es'); })
      .map(function (p) {
        var medidas = [], universales = [], riesgosMap = {};
        data.medidas.filter(function (m) { return m.partido === p.id; }).forEach(function (m) {
          // Los riesgos indirectos se recogen de TODAS las medidas del partido,
          // te afecten o no directamente: ese es su sentido.
          (m.riesgos || []).forEach(function (link) {
            var rid = typeof link === 'string' ? link : link.id;
            var esc = typeof link === 'string' ? 'amplia' : (link.escala || 'amplia');
            var acc = riesgosMap[rid] = riesgosMap[rid] || { medidas: [], amplia: false };
            acc.medidas.push(m.id);
            if (esc === 'amplia') acc.amplia = true;
          });
          if (m.universal) { universales.push(m); return; }
          var e = firstMatch(m.efectos, ans, named);
          if (e) medidas.push(Object.assign({}, m, { valor: e.valor, efecto: e.texto }));
        });
        var riesgos = Object.keys(riesgosMap).map(function (rid) {
          var r = riskById[rid], acc = riesgosMap[rid], ex = Object.assign({}, firstMatch(r.exposicion, ans, named));
          // Si todas las medidas que activan el riesgo son de alcance acotado, la exposición no pasa de "media".
          if (!acc.amplia && ex.nivel === 'alta') {
            ex.nivel = 'media';
            ex.texto += ' (Rebajado a media: en este partido solo lo activan medidas de alcance acotado.)';
          }
          return Object.assign({}, r, { exposicion_usuario: ex, medidas_origen: acc.medidas, escala: acc.amplia ? 'amplia' : 'acotada' });
        }).sort(function (a, b) {
          return (NIVEL[b.exposicion_usuario.nivel] || 0) - (NIVEL[a.exposicion_usuario.nivel] || 0);
        });
        return {
          id: p.id, nombre: p.nombre, programa: p.programa, financiacion: p.financiacion,
          recuento: {
            a_favor: medidas.filter(function (x) { return x.valor > 0; }).length,
            en_contra: medidas.filter(function (x) { return x.valor < 0; }).length,
            incierto: medidas.filter(function (x) { return x.valor === 0; }).length,
            riesgos_altos: riesgos.filter(function (r) { return r.exposicion_usuario.nivel === 'alta'; }).length,
            riesgos_medios: riesgos.filter(function (r) { return r.exposicion_usuario.nivel === 'media'; }).length
          },
          medidas: medidas, universales: universales, riesgos: riesgos
        };
      });
    // Matriz de riesgos: filas = riesgos, columnas = partidos, celda = nivel de exposición (o null si el partido no lo activa).
    var matriz = data.riesgos.map(function (r) {
      var fila = { id: r.id, titulo: r.titulo, evidencia: r.evidencia, niveles: {} };
      partidos.forEach(function (p) {
        var x = p.riesgos.filter(function (y) { return y.id === r.id; })[0];
        fila.niveles[p.id] = x ? x.exposicion_usuario.nivel : null;
      });
      return fila;
    }).filter(function (f) { return Object.keys(f.niveles).some(function (k) { return f.niveles[k]; }); })
      .sort(function (a, b) {
        var m = function (f) { return Math.max.apply(null, Object.keys(f.niveles).map(function (k) { return NIVEL[f.niveles[k]] || 0; })); };
        return m(b) - m(a);
      });

    var notas = (data.notas || []).filter(function (n) { return evalCond(n.si, ans, named); }).map(function (n) { return n.texto; });

    return { meta: data.meta, respuestas: ans, partidos: partidos, matriz_riesgos: matriz, notas: notas };
  }

  return { evalCond: evalCond, visibleQuestions: visibleQuestions, cleanAnswers: cleanAnswers, evaluate: evaluate };
});
```
